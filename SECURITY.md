# Security Policy

## Supported versions

Until the first public release, only the latest commit on the default branch is evaluated for security fixes.

## Reporting a vulnerability

Use GitHub's private vulnerability-reporting feature when it is enabled for the repository. Do not disclose credentials, private user data, or an exploitable issue in a public issue.

Include:

- affected file and version or commit;
- reproduction steps with secrets removed;
- expected and observed behavior;
- likely impact; and
- any safe mitigation already tested.

No external security email address has been published yet. That contact method is `Unresolved` and should be configured before accepting public security reports outside GitHub.
